# No insistir en rotar el token de Supabase

**Decidido por el usuario:** 2026-09-23.

El token personal de Supabase quedo pegado en una conversacion. Se le recomendo
revocarlo y crear otro; el usuario decidio no hacerlo: es el unico que usa su Claude y
confia en el entorno.

**Como aplicar:** no volver a sugerir la rotacion del token. Si hace falta el token para
un comando, usarlo sin recordatorios. Nunca escribirlo en archivos del repositorio: eso
sigue valiendo, porque el repositorio es otra superficie (GitHub, Vercel, colaboradores
futuros).
